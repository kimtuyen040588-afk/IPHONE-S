# 消息 Agent（第一阶段）

这一版已经把 Agent 的权限边界写进了代码：它只能打开 iPhone 的「信息」App，并拍一张**不落盘**的临时截图，供任务日志确认设备状态。

它不能输入收件人、不能输入文案、不能上传图片、不能按发送。这样即使以后接入大模型，模型也不会拥有“自己给陌生人发消息”的权限。

## 现在如何使用

1. 先按 `中文启动说明.md` 完成一台 iPhone 的注册、WDA 签名和连接。
2. 启动 `npm run web` 与 `npm run worker`。
3. 打开后台的 **Agent** 页面，选择设备并点“开始检查”。
4. 打开设备页的任务日志，确认能看到：打开 Messages、截图摘要、`no message sent`。

## 已写好的批次核心逻辑

`createBatchPreview()` 已经可以把“每行一个国际号码”和统一文案变成一个**不发送**的预览：

- 空行会忽略，重复号码只保留第一次；格式错误会拒绝；
- 两台启用设备按 A、B、A、B 平分；
- 每台设备自己的第 2 条会比第 1 条晚 10 秒，两台设备可以同时开始；
- 预览和审计使用文案摘要与 SHA-256 指纹，不把全文塞进日志；
- `POST /plugins/com.phone-farm.messages-agent/batch-preview` 可供网页控制台调用，当前不会创建发送任务。

## 下一阶段

真正的发送器会是另一块“确定性程序”，不把发送权限直接交给 Agent：

```
你确认的号码 + 文案 + 图片摘要
        ↓
不可修改的发送任务
        ↓
确定性发送器（逐条、间隔、不可自动重发）
        ↓
iPhone 的「信息」App
```

Agent 只能帮忙看屏幕、处理弹窗和报告异常；它不能改号码、改文案或绕过确认。

## 可选：让模型看屏幕

默认**关闭**。因为「信息」的截图可能包含私聊内容，程序不会自动把截图传给任何 AI 服务。

如果你明确选择可信的兼容 OpenAI 的视觉模型服务，才在 `.env` 里同时设置：

```dotenv
AGENT_PLANNER_URL=https://你的模型服务/v1
AGENT_PLANNER_API_KEY=你的密钥
AGENT_PLANNER_MODEL=模型名
AGENT_ALLOW_SCREEN_UPLOAD=true
```

即使开启，模型只会得到“设备是否就绪”的受限结果；程序不会把模型写出的文字日志保存下来，防止它意外复述屏幕上的消息。
